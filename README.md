# QR-Studio-Generator
QR Studio adalah aplikasi web satu halaman untuk membuat kode QR yang bisa disesuaikan tampilannya langsung dari browser. Pengguna dapat mengatur warna kode dan latar QR, menambahkan judul serta tagline dengan pilihan font dan warna masing-masing, mengubah ukuran QR dan jarak tepi kartu, lalu mengunduh hasilnya dalam format PNG, JPG, PDF, atau HTML. Seluruh proses berjalan di sisi klien tanpa server maupun database, dibangun murni dengan HTML, CSS, dan JavaScript, memanfaatkan QRious untuk pembuatan kode QR dan jsPDF untuk ekspor PDF. Tampilannya responsif, nyaman digunakan baik di desktop maupun perangkat mobile.
